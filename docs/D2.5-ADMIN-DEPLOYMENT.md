# Phase D2.5：数据管理台部署说明

## 架构

```
浏览器 → SSH隧道 → localhost:8787/admin → sankengcloset_service API → PostgreSQL
```

## 访问方式

### SSH 隧道（推荐）

```bash
ssh -L 8787:127.0.0.1:8787 admin@你的服务器IP
```

然后浏览器打开：`http://localhost:8787/admin`

### 直接访问（仅限内网/临时测试）

```bash
# 需要防火墙放行 8787 端口
curl http://服务器IP:8787/admin
```

## 登录

- 用户名：`admin`
- 密码：环境变量 `ADMIN_PASSWORD`（默认 `sankeng2025`）

## 功能模块

| 模块 | 功能 |
|------|------|
| 📊 概览 | 商品总数、品牌数、坑向分布、待审核数 |
| 🏷️ 品牌 | 品牌列表、商品数、价格范围、查看品牌商品 |
| 📦 商品 | 商品列表、坑向筛选、名称搜索、商品详情 |
| ✅ 审核 | 待审核队列、审核通过/驳回、填写原因 |
| 📈 质量 | 缺图片/品牌/价格/状态统计 |
| 🔄 采集 | 采集任务记录、错误日志 |

## 安全

- PostgreSQL 仅监听 127.0.0.1:5432
- API 仅监听 0.0.0.0:8787（需 SSH 隧道）
- Token 24 小时过期
- 密码通过环境变量配置
- `.env` 不提交 Git

## 启动

```bash
cd sankengcloset_service
DATABASE_URL=postgres://sankeng:***@localhost:5432/sankeng \
  node --env-file-if-exists=.env --import tsx src/server.ts
```

## 备份

```bash
docker exec postgres pg_dump -U sankeng sankeng > backup_$(date +%Y%m%d).sql
```

## 恢复

```bash
cat backup_20250101.sql | docker exec -i postgres psql -U sankeng sankeng
```
