# 收藏、榜单与数据边界修复 — 2026-09-09

## 已实现

- 收藏统一持久化入队后乐观更新，移除跨商品全局请求序号和并行直写。队列单飞、按序重放，失败不越过前置操作；冲刷时新加入的操作保留并继续处理。存储失败不改变收藏显示。
- 登录后重放游客操作并刷新远端收藏 ID；队列绑定用户，其他账号操作不发送。刷新时保留待同步删除和状态变更，收藏重放透传 releaseId。
- 独立 favorite 排行接口。收藏榜按当前 wishlist 关系总数降序，热榜按 feed_score 降序；同分按商品 ID 降序。SQL 在全部已发布、未删除商品中排序后截取。收藏数包含各决策状态，不表示历史累计次数或净增长；缺失 favoriteGrowth 不使用总量冒充。
- 真正空列表保持为空，网络错误抛给页面展示重试。Feed、搜索、榜单、品牌、商品、日历、趋势及公开动态仅在显式模拟登录时使用演示内容。演示收藏/关注使用独立存储前缀；模拟操作不发送真实收藏请求。
- 首页分页失败保留数据、cursor 和 hasMore，支持点击重试；过时分页错误不能覆盖刷新结果。商品详情网络失败不再标为可清除的失效收藏。
- AppImage 地址变化重置加载状态；移除商品详情未使用的 createPurchase、spotPriceCents、oldPrice。删除无实现的内容 Store 通知调用。
